# Tim Uhl — Portfolio Website

## Starten

1. Installiere Node.js, falls es noch nicht installiert ist.
2. Entpacke die ZIP-Datei.
3. Öffne den Ordner `tim-uhl-portfolio` in VS Code.
4. Öffne das Terminal in VS Code.
5. Führe diese Befehle aus:

```bash
npm install
npm run dev
```

6. Öffne die angezeigte lokale Adresse, normalerweise `http://localhost:5173`.

## Build prüfen

```bash
npm run build
```

## Vor der Veröffentlichung prüfen

- Skills in `src/App.jsx` an den tatsächlichen Kenntnisstand anpassen.
- Projektbeschreibungen und Jahreszahlen kontrollieren.
- E-Mail-Adresse und Kontaktdaten prüfen.
- Einen echten Lebenslauf als PDF ergänzen, falls ein Download angeboten werden soll.
- Das Bootcamp-Abschlussprojekt erst als fertig kennzeichnen, wenn es tatsächlich fertig ist.

Die Website verwendet React, Vite und Lucide React. Die fünf bereitgestellten Bilddateien liegen in `public/images`.
